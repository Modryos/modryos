Modryos / Features

Features

Modryos is a desktop app for making Minecraft Java Edition mods without writing code. The pictures on this page are from Modryos and from the game. The features are tested automatically in the game on NeoForge and Fabric, on all five supported versions. The last full test run passed 17,570 of 17,577 checks.

Modryos is not released yet. 1.0.0 is coming soon.

Start

Getting started

Click New and choose a type from seven groups: blocks and items, crafting and loot, machines and networks, mobs and models, logic and code, the world, and screens and guides. Each type has a short description and opens with its settings.

Models, textures and animation

Models, textures and animation

The model editor shapes blocks, items and creatures with a live 3D preview. Textures are painted pixel by pixel, and animations are made on a timeline. Models and animations look the same in the game.

Creatures

Creatures

Model and animate a creature, then choose its behaviours from a list, such as how it moves and what it does. Creatures can be tamed and ridden.

Blocks, items and armour

Blocks, items and armour

Create blocks, items, tools, weapons, armour, food and fuel. Bows and crossbows have their own draw settings, armour is shown on the player, and items can store energy with a charge bar.

Recipes

Recipes

Create crafting recipes and the game's other recipe types by placing items in a grid. The recipes appear in JEI and other recipe viewers.

Machines, energy and pipes

Machines, energy and pipes

A machine is a block with inputs, outputs, energy and a screen. Energy cells store and transfer power. Cables, fluid pipes and item ducts connect machines, and each side of a block can be set to input, output, redstone control or a filter.

Screens and HUD

Screens and HUD

Machine screens, HUD bars, books and quest pages are built by dragging controls onto the screen. Each control can show data from the mod, such as a tank's level or a player's mana. The screen looks the same in the game.

Quests, books and skill trees

Quests

Quests are arranged in chapters on a map. Each quest page is designed in the screen builder and looks the same in the game. Guide books, bestiaries with search, skill trees and altar rituals are built the same way.

Rules and Java

Rules and Java

Rules are built from ready-made sentences, for example: when the sword hits something, set it on fire. Conditions can be grouped with If, Else if and Else. Each rule is Java code underneath, you can open the code at any time, and you can add your own Java classes and mixins to the same project.

Play and test

Testing in the game

The Play button starts Minecraft with your mod on the version and loader you choose, with one or two players on the same PC. Recipes and other data update with a reload, and many code changes apply while the game is running, so most changes do not need a restart.

Versions and loaders

Versions and loaders

One project builds the mod for NeoForge and Fabric on all of these Minecraft Java Edition versions. Modryos creates a jar file for each version and loader you choose, ready to upload to CurseForge or Modrinth.
