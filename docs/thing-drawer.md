# Drawer

A block that holds many of one item, shown on its front.

## How to add it

- New thing > Machines and networks > Drawer


## What you can set

### Drawer

| Setting | What it does |
| --- | --- |
| Holds | How many stacks of its item it holds. A capacity upgrade adds to it. From 1 to 100000 stacks. |
| Shows on front | Draws the item and how many on its front. |
| Keeps its item | Emptied, it still holds the place of its item, so only that item goes in again. |
| Voids the rest | Full, it still takes its item and destroys what does not fit, so a hopper or a pipe never backs up. |
| Kinds it holds | How many kinds it holds at once: 1, 2 side by side, or 4 in two rows. Each place has its own item and count. Click a place to put in or take out there. Choose one of: 1, 2, 4. |
| Compacts | One drawer for a whole chain, such as nugget, ingot and block. Any of them goes in and comes out, counted together. |
| The chain | The items, smallest first. Each is worth the next step's number of the one before. |
| Each step is worth | How many of one make the next, such as 9 nuggets or ingots for the one above. Match the recipes that craft them. From 2 to 64. |
| Hides the item | Its front does not show the item. A key item with the Turn a drawer setting action turns this on and off in the game. |
| Shows how many | Its front says how many. A key item with the Turn a drawer setting action turns this on and off in the game. |

### Takes upgrades

| Setting | What it does |
| --- | --- |
| Upgrades it takes | How many upgrades it holds at once: in a block with an inventory, the last places of it, slots of its screen. They fall out when it is broken. From 0 to 16. |
| Takes tiers up to | The highest tier of upgrade it takes: an upgrade of a higher tier does not go in. From 1 to 5. |
| Tier | How many times over it works, holds and moves from the start, before any upgrade: 1 is as its numbers say. From 1 to 64 times. |
| A tier of | The block of its set whose recipes it runs, so a higher tier makes what the first one makes. |

Every block also has the settings on the [Block](editor-block.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Drawer, Takes upgrades.
