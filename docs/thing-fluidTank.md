# Fluid tank

A tank that holds 8000 mB and opens its own screen.

## How to add it

- New thing > Machines and networks > Fluid tank

This makes several things at once: [Tank](thing-tank.md).

## What you can set

You set each part in its own editor, linked above.

## What it becomes in the game

Each part becomes what its own page says.

## What it works with

It does not point at other things.
