# Mailbox

Sends letters and keeps each player's post.

## How to add it

- New thing > Machines and networks > Mailbox


## What you can set

### Mailbox

| Setting | What it does |
| --- | --- |
| Rows of post | How many rows of letters its screen shows at once. The rest wait for the next time. From 1 to 6. |

Every block also has the settings on the [Block](editor-block.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Mailbox.
