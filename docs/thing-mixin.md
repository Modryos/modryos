# Mixin

A piece of your own code that changes one of the game's classes, listed in your mixin config for you. It takes its name from this thing's name until you write in it.

## How to add it

- New thing > Logic and code > Mixin


## What you can set

The main settings are below. The [File of your own](editor-ownFile.md) editor lists every setting.

| Setting | What it does |
| --- | --- |
| Name | What you call it here. |
| File | Where it is: resources/common reaches every target, resources/neoforge and resources/fabric one each. |

## What it becomes in the game

It is not part of the game itself: it describes another mod or a file, so it has no side to choose.

## What it works with

It does not point at other things.

Other things that open the same editor: [File of your own](thing-ownFile.md), [Pack file](thing-packFile.md), [Dimension file of your own](thing-dimensionFile.md), [Look of a block made in code](thing-blockLook.md), [Mixin config](thing-mixinConfig.md), [Access widener (Fabric)](thing-accessWidener.md), [Access transformer (NeoForge)](thing-accessTransformer.md).
