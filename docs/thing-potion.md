# Potion

A drink that gives an effect.

## How to add it

- New thing > Crafting and loot > Potion


## What you can set

The main settings are below. The [Potion](editor-potion.md) editor lists every setting.

| Setting | What it does |
| --- | --- |
| Name | The bottle's name. Its splash, lingering and arrow forms are named from it. |
| Game name | The potion's name in the game, as /give and a data pack name it. |
| Effects | What drinking it gives, each for its time and at its level. Each row has: Effect, For, Level, Swirls. |
| Brewed with | What goes in the top of the brewing stand to make it. |
| From | The potion it is brewed from, most often the Awkward Potion a Nether wart makes. |

## What it becomes in the game

It is not part of the game itself: it describes another mod or a file, so it has no side to choose.

## What it works with

It points at: [Effect](editor-effect.md).
