# Help and community

## The Help menu

- **Getting started** walks you through your first mod.
- **Documentation** opens these guides in your browser.
- **Keyboard shortcuts** lists every key you can press, and lets you search.
- **Help for this editor** opens the guide page for the editor you are in.
- **What's new** shows what changed in this version.
- **Contact support** writes an email to the Modryos team. It starts with the version you use.
- **The Modryos community** opens the place where makers help each other.
- **Report a problem** shows what would go in a report first, and saves nothing until you say yes.

## Report a problem

Press **F6** or choose **Help > Report a problem**. Write one line about what you expected. You see everything that goes in the report before it is saved.

## Contact support

Write to support@modryos.com. A person reads it.
