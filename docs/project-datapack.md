# Data pack project

Recipes, drops, tags and world data with no code, for a plain game.

## How to add it

- Start screen > New project > Data pack

## What you can set

It can hold: [Recipe](thing-recipe.md), [Tag](thing-tag.md), [Advancement](thing-advancement.md), [Loot table](thing-lootTable.md), [Condition](thing-condition.md), [Item change](thing-itemChange.md), [Feature](thing-feature.md), [Caves](thing-carver.md), [Structure](thing-structure.md), [Biome](thing-biome.md), [Dimension](thing-dimension.md), [Damage type](thing-damageType.md), [Enchantment](thing-enchantment.md), [Commands to run](thing-function.md).

## What it becomes in the game

A pack you copy into a world's datapacks or resourcepacks folder.

See [Versions and loaders](versions-and-loaders.md).
