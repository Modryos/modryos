# Resource pack project

Textures, models, sounds and translations for the game's own things.

## How to add it

- Start screen > New project > Resource pack

## What you can set

It can hold: [Texture](thing-texture.md), [Translation](thing-translation.md), [Sound](thing-sound.md), [Painting](thing-painting.md).

## What it becomes in the game

A pack you copy into a world's datapacks or resourcepacks folder.

## What it works with

See [Versions and loaders](versions-and-loaders.md).
