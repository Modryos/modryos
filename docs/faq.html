Frequently asked questions

Can I make a mod without coding?#

Yes. You build blocks, items, creatures and recipes in the studio. If you do want code, it is there too.

What is Modryos?#

A studio where you build the whole mod - models, animations, textures, recipes, logic and code - in one place. AI is an optional helper.

Which versions and loaders?#

Minecraft Java Edition 1.21.1, 1.21.11, 26.1.2, 26.2 and 26.3, on NeoForge and Fabric, from the same project. See Versions and loaders.

Which computers does it run on?#

Windows 10 and 11.

Is it free?#

Yes, during the beta. Modryos AI is not open in the beta, and the studio works fully without it.

I have no invite. What now?#

Press Join the waiting list on the sign-in screen. Invites go out in small waves. Confirm your address from the email we send, because only confirmed places get invites.

My invite code does not work.#

Each code is used once and belongs to the address it was sent to. Sign in with that exact address, then paste the code. Still not working? Write to support@modryos.com.

Windows says the installer is not safe.#

The beta installer is not signed yet. Check the file as shown in Install, then press More info and Run anyway.

Play takes a long time the first time.#

The first Play downloads the game and its tools once, about 1.7 GB. Later starts are fast.

My mod is not in the game.#

Look for its name in the mod list. If it is missing, open the Cook window and read the first red line. See Troubleshooting.

How do I put my mod on Modrinth or CurseForge?#

Make the mod file, then use the files Modryos writes for the stores. See Publishing.

I lost my work.#

Your project keeps restore points. Open File > Versions and open an older one. Please do not delete the project folder. Press F6 and send us a report.

Do I need to know Java?#

No.

What do you keep about me?#

Only your account. Press Download my data in Settings > Account to see it, or Delete account to remove it. Your mods never leave your computer. See the Privacy Policy.

Who do I ask for help?#

Write to support@modryos.com, or ask the community.
