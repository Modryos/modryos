# Getting started

Modryos is a studio for making Minecraft mods. You build the whole mod - models, animations, textures, recipes, logic and code - in one studio. AI is an optional helper.

You do not need to know how to code. If you know Minecraft, you can start.

## The five steps

1. [Install Modryos](install.md): download it, start it, sign in.
2. [Your first mod in 10 minutes](first-mod.md): pick a sample, change one thing.
3. [Play](play.md): see your mod in the real game.
4. [Export](export.md): make the mod file you can share.
5. [Publish](publishing.md): put it on Modrinth or CurseForge.

## Good to know

- Your projects stay on your computer.
- One project can make a mod for NeoForge and Fabric. See [Versions and loaders](versions-and-loaders.md).
- Stuck? Read [Troubleshooting](troubleshooting.md), the [FAQ](faq.md) or [Help and community](help-and-community.md).
