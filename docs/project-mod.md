# Mod project

Blocks, items, recipes and everything else, built for NeoForge and Fabric.

## How to add it

- Start screen > New project > Mod

## What you can set

A mod can hold every kind of thing in the New thing dialog.

## What it becomes in the game

A [jar](glossary.md#jar) for each [loader](glossary.md#loader) and game version you pick, made by [Cook](glossary.md#cook).
