# Berry bush

A block that ripens in a minute in the light and gives berries when a player picks it, then grows again.

## How to add it

- New thing > The world > Berry bush


## What you can set

### Grows over time

| Setting | What it does |
| --- | --- |
| Ripe in | How long it takes to ripen from the start, while it has its light. From 1 to 86400 seconds. |
| Light it needs | The least light where it stands for it to grow, from 0 (dark) to 15 (day). From 0 to 15. |
| Gives | What falls out when a player picks it ripe. |
| How many | How many of it each time. From 1 to 64. |
| Once picked | It grows again from the start, as a berry bush does, or it is gone, as a fruit picked from the ground. Choose one of: it grows again, it is gone. |

Every block also has the settings on the [Block](editor-block.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Grows over time.
