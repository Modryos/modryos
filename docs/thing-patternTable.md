# Pattern table

Turns a blank pattern into a recipe for the crafter.

## How to add it

- New thing > Machines and networks > Pattern table


## What you can set

### Pattern table

| Setting | What it does |
| --- | --- |
| Pattern item | The blank it turns into a pattern. None: paper. |
| Writes the pattern onto | Another item (one of another mod's too, typed as its id) that the table fills in with the recipe, instead of making its own pattern. Empty: the table makes its own pattern. Its blank goes in the blank slot. |
| What is written | The data to put on that item, as JSON with the item's data pieces by name. Blanks are filled from the grid: (input1) to (input9), (output) and (outputCount). |
| Screen | Its screen, laid out on the Screen tab: the grid, the blank, the pattern. |

Every block also has the settings on the [Block](editor-block.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Pattern table.
