# Crafting station

A block with a 3x3 grid and a result, like a crafting table.

## How to add it

- New thing > Machines and networks > Crafting station

This makes several things at once: [Machine](thing-machine.md), [Station recipe](thing-stationRecipe.md).

## What you can set

You set each part in its own editor, linked above.

## What it becomes in the game

Each part becomes what its own page says.

## What it works with

It does not point at other things.
