# Crate

An item that opens into a loot table when used, made with its table.

## How to add it

- New thing > Blocks and items > Crate


## What you can set

### Opens into loot

| Setting | What it does |
| --- | --- |
| Loot table | The loot table it opens into. |
| Used up | It is gone once opened. Off, it can be opened again and again. |
| Rarity | Sets its color and whether it shimmers; its name is shown in the color past Common. Choose one of: Common, Rare, Epic, Legendary. |
| Color | The color its picture is drawn in and its name is shown in. |
| Shimmers | It shimmers as an enchanted thing does. |

Every item also has the settings on the [Item](editor-item.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Opens into loot.
