# Glossary

**New thing**: New thing

**Cook**: Build a jar for each target picked, one after another, and put them side by side in the project's release folder.

**Play**: Build the mod and start a Minecraft client with it.

**Export**: Writes your project out as files you can share or keep.

**Build the jar**: Build the mod for every target the project lists, one after another, without starting a game.

**Project**: A folder that holds everything for one mod, data pack or resource pack.

**Thing**: One block, item, creature, recipe or other piece you add to a project.

**Kind**: The sort of a thing: a block, an item, a recipe. Each kind has its own editor.

**Editor**: The panel where you set one thing: its name, its look and what it does.

**Loader**: The program that runs mods in Minecraft. Modryos makes mods for NeoForge and Fabric.

**Target**: Set the targets the mod is made for: the loaders and game versions Cook makes jars for.

**Sample**: Your copy goes in its own folder. The sample stays as it is.

**Template**: A thing that already works, added from New thing, such as a Crusher or a Coal Generator.

**Restore point**: Replay the edits made after the last save.

**Trait**: An ability attached to a thing, such as an inventory or an energy store.
