# Set

Makes an ore, its ingot, tools and armor, with recipes.

## How to add it

- New thing > Blocks and items > Set

This makes several things at once: [Ore](thing-ore.md), [Tool](thing-tool.md), [Weapon](thing-weapon.md), [Armor](thing-armour.md), [Recipe](thing-recipe.md), [Drop](thing-drop.md).

## What you can set

You set each part in its own editor, linked above.

## What it becomes in the game

Each part becomes what its own page says.

## What it works with

It does not point at other things.
