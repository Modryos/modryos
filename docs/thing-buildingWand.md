# Building wand

A wand that lays a line, a wall or a box of blocks from a corner a player marks to the block it is used on, outlining it first.

## How to add it

- New thing > Blocks and items > Building wand


## What you can set

### Acts on many blocks

| Setting | What it does |
| --- | --- |
| What it does | Line: blocks in a straight run from the marked corner to the block used on. Wall: a wall standing on that run, as high as the two corners are apart. Box: the whole box between them. Copy: the box between the marked corner and the block used on is copied, then each use pastes it. Tree: mining a log fells every log of the tree. Vein: mining a block breaks every joined block of its kind. Choose one of: A line, A wall, A box, Copy and paste, Fell a tree, Mine a vein. |
| At most | The most blocks one action places, copies or breaks, 1 to 4096. From 1 to 4096. |
| Places | The block it places: the one in the player's other hand, or one chosen here. Choose one of: Off-hand block, A chosen block. |
| Block | The block it places, picked by its name in the game's list of blocks. |
| Only | The blocks it starts on: one block, or a group of blocks such as every ore. Empty: any block; a tree always starts on a log. |
| Uses up blocks | Each block placed is taken from the player's inventory, as placing it by hand would; off, it places for free. In creative it is always free. |
| Turns with you | A paste is turned as far as the player has turned since the copy: copied facing north, pasted facing east, it is turned a quarter, doors and stairs too. |
| Outline first | While it is held, what it would place, copy or break is outlined round the block under the cross, before anything is done. |
| Can undo | Used in the air while sneaking, it puts back what its last action changed and gives the blocks back, up to ten actions back. |

Every item also has the settings on the [Item](editor-item.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Acts on many blocks.
