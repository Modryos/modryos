Laid out in the studio, opened in the game. Minecraft 1.21.1, NeoForge and Fabric.

Models and animation

Shape it, paint it, make it move.

A model editor with a live 3D preview, a pixel painter for textures, and a timeline for animations. The wyrm here was modelled, its scales painted and its breathing animated this way, all in the same project as the rest of the mod.

Screens

Build a screen here. Open it there.

Machine screens, HUD bars, books and quest views. Drag controls onto the screen, give them a look, and tie them to what the mod knows: the foods a player has tasted, a tank's level, their mana. What you lay out is what opens in the game.

then Play
Rules

Say what happens. In sentences, or in Java.

When the sword hits something, set it on fire, and if it was a player, warn whoever holds the sword. Conditions nest into groups the way a game engine's visual scripting does. Each sentence is Java underneath, and the code view is always one click away.

Quests

Quests on a map.

Chapters, quests and the lines between them, drawn on a map. Each quest's page is laid out in the screen builder, like the one at the top of this page.

Versions

Every version kept.

Save a version whenever you like, compare any two, and see what changed, element by element. Here a dragon scale's stack size went from 64 to 16.

More from a running game.

Machine screens and a HUD bar, each built in the studio and photographed in the game.
