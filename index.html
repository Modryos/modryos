Make Minecraft mods
without coding.

Modryos is a desktop app for making Minecraft Java Edition mods. It includes a model editor, a texture painter, an animation timeline, a screen builder, quests and rules, and you can test the mod in the game from the app.

Watch on GitHub See examples

To start, click New and choose what to make: a block, a tool, a machine, a creature, a screen and more.

1 · Models and animation

Models, textures and animation

The model editor has a live 3D preview. Textures are painted pixel by pixel, and animations are made on a timeline. The dragon in these pictures was made this way.

2 · Screens

Screens and HUD

Machine screens, HUD bars, books and quest pages are built by dragging controls onto the screen. Each control can show data from the mod, such as a tank's level or a player's mana. The screen looks the same in the game.

then Play
3 · Rules and code

Rules and Java

Rules are built from ready-made sentences, for example: when the sword hits something, set it on fire. Conditions can be grouped with If, Else if and Else. Each rule is Java code underneath, you can open the code at any time, and you can add your own Java classes and mixins.

4 · Quests

Quests

Quests are arranged in chapters on a map. Each quest page is designed in the screen builder and looks the same in the game.

5 · Versions

Version history

Save a version at any time and compare two versions to see what changed. In this example, a dragon scale's stack size changed from 64 to 16.
