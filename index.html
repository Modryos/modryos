The mod engine
for Minecraft.

You build the whole mod - models, animations, textures, recipes, logic and code - in one studio. AI is an optional helper. Press Play and the mod opens in the game.

Request access See what it makes

Every mod starts here: press New and pick what to make, from a block or a tool to a machine, a creature or a screen.

1 · Models and animation

Shape it, paint it, make it move.

A model editor with a live 3D preview, a pixel painter for textures, and a timeline for animations. The Ember Fox here was modelled, painted and given its walk this way, all in the same project as the rest of the mod.

2 · Screens

Build a screen here. Open it there.

Machine screens, HUD bars, books and quest views. Drag controls onto the screen, give them a look, and tie them to what the mod knows: a tank's level, their mana, the pages of a guide book. What you lay out is what opens in the game.

then Play
3 · Rules and code

Say what happens. In sentences, or in Java.

When the sword hits something, set it on fire, and if it was a player, warn whoever holds the sword. Conditions nest into groups the way a game engine's visual scripting does. Each sentence is Java underneath, the code view is one click away, and your own Java classes and mixins sit right beside it.

4 · Quests

Quests on a map, pages as you drew them.

Chapters, quests and the lines between them, drawn on a map. Each quest's page is laid out in the screen builder and opens in the game exactly as you drew it.

5 · Versions

Every version kept.

Save a version whenever you like, compare any two, and see what changed, element by element. Here the Blaze Sword's rule changed from putting out fires to healing too.
