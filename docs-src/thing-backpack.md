An item with slots of its own, opened from the hand.

## How to add it

- New thing > Blocks and items > Backpack


## What you can set

### Holds items

| Setting | What it does |
| --- | --- |
| Slots | How many stacks it holds. From 1 to 54. |
| Slots mark items | The slots keep a picture of an item instead of the item. A player clicks an item on a slot to mark it, and clicks with an empty hand to clear it, so nothing is ever taken from them. This is how a filter you can edit in the game works. |
| Picks up | Carried anywhere in the inventory, it takes what the player walks over before the player's own slots do. |
| Picks up only | The items it picks up, each an item or a #tag. Empty, it picks up anything that fits in it. |
| Only what it holds | It only picks up the kinds already in its slots. Put one in to teach it. |
| Most in a slot | How many of one item a slot holds. 64 is the game's own; set it higher for a slot that holds thousands. From 1 to 2147483647. |
| Keeps at least | When something is taken out, this many stay in the slot. 0 lets the slot empty. From 0 to 99999. |
| Uses what it holds | Used, it acts as the thing chosen in it: the last one you clicked in its slots. Crouching, it opens them. |
| Holds other bags | Other things that hold items can go inside it, so you can carry a bag of bags. Off, it refuses them, as a shulker box does. |
| Packs nine into one | While you carry it, nine of a thing in your slots turn into what the crafting grid makes of nine (nine iron ingots become an iron block). |
| Put down as | Used while crouching on the ground, it becomes this block, holding what it held. Break it, or crouch and use it with an empty hand, and it is the same item again, with its name and colour. |
| Most slots with pockets | The most slots it can have once pockets are put in it. Its screen has room for all of them; the ones not opened yet are dark. 0 means it takes no pockets. From 0 to 54. |
| Opens from the inventory | While it is worn, a button on the player's own inventory screen opens it. It drops with its contents when the player dies. |
| Screen | Its screen, laid out on the Screen tab. Until it is changed there, the product draws the slots in rows. |

Every item also has the settings on the [Item](editor-item.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Holds items.
