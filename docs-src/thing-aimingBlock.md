A block that keeps a [target](glossary.md#target) place: a launcher's, a gate's other end. Where it comes from is your choice, and rules change it any time.

## How to add it

- New thing > Machines and networks > Aiming block


## What you can set

### Aims at a place

| Setting | What it does |
| --- | --- |
| Name of the target | The name the target is kept under, among the block's own numbers (name X, Y and Z). Rules that keep or read a place by this name reach it too. |
| Where it aims | Where the target comes from. Kept: the numbers below, or what a rule, a command or a designator wrote. The others are looked for each time it is asked. Choose one of: The numbers kept in it, A place the world remembers by name, The block it is linked to, The nearest block on a channel, A mob or player on a pointer's channel. |
| East or west (X) | Where it aims at first, along east and west. A rule or a designator item changes it later. From -30000000 to 30000000. |
| Height (Y) | Where it aims at first, how high. From -2048 to 2048. |
| North or south (Z) | Where it aims at first, along north and south. From -30000000 to 30000000. |
| Name of the place | A place the world remembers under this name (a rule or a designator item keeps it); the block follows it when it moves. |
| Channel | The channel's name: blocks linked on it, or mobs and players a rule put on it. |
| Looks as far as | How far from the block it looks for the nearest one, in blocks. From 1 to 30000000 blocks. |

Every block also has the settings on the [Block](editor-block.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Aims at a place.
