## New thing

The button that opens the catalogue of everything you can add to a project.

## Cook

Build a jar for each target picked, one after another, and put them side by side in the project's release folder.

## Play

Build the mod and start a Minecraft client with it.

## Export

Writes your project out as files you can share or keep.

## Build the jar

Build the mod for every target the project lists, one after another, without starting a game.

## Project

A folder that holds everything for one mod, data pack or resource pack.

## Thing

One block, item, creature, recipe or other piece you add to a project.

## Kind

The sort of a thing: a block, an item, a recipe. Each kind has its own editor.

## Editor

The panel where you set one thing: its name, its look and what it does.

## Loader

The program that runs mods in Minecraft. Modryos makes mods for NeoForge and Fabric.

## Target

Set the targets the mod is made for: the loaders and game versions Cook makes jars for.

## Sample

Your copy goes in its own folder. The sample stays as it is.

## Template

A thing that already works, added from New thing, such as a Crusher or a Coal Generator.

## Restore point

Replay the edits made after the last save.

## Trait

An ability attached to a thing, such as an inventory or an energy store.

## Jar

The file a mod lives in, ending in .jar. A player puts it in the mods folder of Minecraft. Cook makes one for every version and loader you pick, and each works only on its own.

## EULA

The Minecraft licence from Mojang that you accept once, with Accept and Play, before the studio starts the game for you.

## Release folder

The folder called release inside your project. Cook puts the jars there, in a folder named for the mod version.

## Fabric API

A separate mod that every Fabric mod needs next to it in the mods folder. NeoForge mods do not need it.

## SHA256

A long code worked out from a file. If the code you get matches the one on the download page, the file was not changed on the way.

## Painter

The part of the Texture editor where you draw a picture pixel by pixel.

## Texture

The picture a block, item or creature wears. It is a PNG file, often 16 by 16 pixels.

## Strip of frames

A picture made of squares one above the other, like a film strip. The game shows them one after another, so the picture moves.
