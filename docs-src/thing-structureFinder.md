An item that finds the nearest of the structures it names and shows the way: an eye for a dungeon, a map stone for ruins.

## How to add it

- New thing > The world > Structure finder


## What you can set

### Finds a structure

| Setting | What it does |
| --- | --- |
| Finds | The structures it finds: your own, the game's, or a tag of them; the nearest of any of them. |
| Shows the way | A trail of light toward it, its direction and distance over the hotbar, or both. Choose one of: A trail of light, Direction and distance, Both. |
| Looks as far as | How far it looks, in blocks; farther takes the server longer. From 16 to 6400 blocks. |
| Breaks | The chance it breaks each use, in percent; the game's eye breaks one time in five. From 0 to 100 percent. |
| Rest | Seconds before it can be used again. From 0 to 600 seconds. |

Every item also has the settings on the [Item](editor-item.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Finds a structure.
