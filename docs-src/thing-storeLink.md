A block that joins the chests beside it to every other link in range, with no cable: a spark or a crystal.

## How to add it

- New thing > Machines and networks > Link


## What you can set

### Links without cables

| Setting | What it does |
| --- | --- |
| Range | How far it reaches another link. From 1 to 64 blocks. |
| Bridge name | Give two links the same name and they join the stores beside them at any distance and in any dimension, as a pair. Empty: only links in range. |
| Reaches other worlds | On: bridges with the same name join even when one is in the Nether and one in the Overworld. Off: only bridges in this world join. On by default. |
| Keeps its place loaded | On: the land around this bridge stays loaded while it stands, so it keeps working when you walk far away. |
| Opens | What using the link does: nothing (the index answers in chat), or opens the store screen with a search box over all the stores it joins. Choose one of: The chat, The store screen. |

Every block also has the settings on the [Block](editor-block.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Links without cables.
