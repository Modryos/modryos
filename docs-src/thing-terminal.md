Lists what the network holds, to take and put by clicks.

## How to add it

- New thing > Machines and networks > Terminal


## What you can set

### Terminal

| Setting | What it does |
| --- | --- |
| Screen | Its screen, laid out on the Screen tab: the stored items, a search box, the inventory. |
| Makes from | What its list of things to make holds: the crafters' patterns, or every crafting recipe what it reaches can make, crafted into the player's hands (a recipe book). Choose one of: The crafters' patterns, Every recipe it can make. |
| Only | A test of what it lists, as a slot test is written: a thing, a tag, a value or some data. Empty: everything. |
| Sorted by | The order of the list: by name, by how many it can make, by how much food, or by a value. Choose one of: Name, How many, Food, A value. |
| Value | The value it sorts by, most first. |

Every block also has the settings on the [Block](editor-block.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Terminal.
