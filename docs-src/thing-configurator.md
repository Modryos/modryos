A tool that sets the faces of a placed block: right-click a face to step its mode, sneak to go back.

## How to add it

- New thing > Machines and networks > Configurator


## What you can set

### A configurator

| Setting | What it does |
| --- | --- |
| Sets | Which thing it carries a click steps: all the block carries, or one. Choose one of: Everything the block carries, Items, Fluid, Energy. |
| Works on | The blocks it sets. None listed: every block whose faces a player sets. |
| Sneaking goes back | Sneak and click to step to the mode before. Off, sneaking steps forward too. |

Every item also has the settings on the [Item](editor-item.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: A configurator.
