Put into a backpack in the crafting grid, it adds nine slots.

## How to add it

- New thing > Blocks and items > Pocket


## What you can set

### Module

| Setting | What it does |
| --- | --- |
| Goes into | What it can be installed into. Choose one of: Anything that takes modules, A tool, A weapon, Armor, Something that holds items. |
| Gains levels by | How it goes up a level: put in again (each time one more level), or by what the one wearing or holding it does. Choose one of: Putting it in again, What the player does. |
| Counts | What the player does that counts toward its next level while the thing it goes into is worn or held. Choose one of: Blocks run, Blocks walked, Blocks swum, Blocks flown, Blocks fallen, Jumps, Damage taken, Damage dealt, Mobs killed, Blocks mined, Seconds worn. |
| For each level | How much of what it counts makes one more level: 100 blocks run is level 1, 200 is level 2, up to its most levels and the room the thing has for it. From 1 to 100000000. |
| Energy each use | What it spends of the item's energy each block mined or hit, or each second while worn; nought and it costs nothing. From 0 to 1000000000. |
| Changes the tool | What it changes of the item it is installed in while switched on, each level once more: any stat, the game's or a material's own. Each row has: Stat, How, Amount, Only on blocks. |
| Most levels | Installed again it goes up a level, to this many. From 1 to 100. |
| Slots a level | How many of the host's slots each level takes. From 0 to 54. |
| Put in by hand | Used while the thing it goes into is in the other hand, it goes in (a gem into a socket). That thing used crouching with the other hand empty gives the last one back. |

Every item also has the settings on the [Item](editor-item.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Module.
