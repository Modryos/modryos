A filter as an item: marked in the filter of a pipe's face, that face lets through what its rules say, items and tags, mods, wear and enchantment.

## How to add it

- New thing > Machines and networks > Item filter


## What you can set

### A filter

| Setting | What it does |
| --- | --- |
| Items and tags | The items it names, or every item of a tag. Names nothing and no mods: every item. |
| Mods | Every item of these mods, by the mod's id (minecraft for the game's own). |
| Wear | Which items pass by their wear: any, unworn (and things that never wear), worn, or a quarter of their uses or less left. Choose one of: Any, Unworn, Worn, Nearly broken. |
| Enchanted | Whether items must be enchanted, must not be, or either. Choose one of: Either, Only enchanted, Only plain. |
| Genes | Genes an item must show to pass, every line at once, such as species Goldbloom or Growth at least 5. An item with no genes does not pass. Each row has: Gene, Is, Value. |
| Has data | Data the item must carry beyond what it comes with, every one: custom name, enchantments, potion contents, damage. Empty asks nothing. |
| Made of | Stock types the item must hold some of, any one: Fire, Earth, or a kind for all its types. Empty asks nothing. |
| Marks match data too | For a filter whose player marks items in the game: a marked sword only lets through swords with the same enchantments and name. Off, any sword matches. |
| Way round | Lets only what it names through, or everything but it. Choose one of: Only these, All but these. |

Every item also has the settings on the [Item](editor-item.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: A filter.
