An item that holds many kinds of item by count. Put it in a drive; carry it away full.

## How to add it

- New thing > Machines and networks > Storage disk


## What you can set

### Storage disk

| Setting | What it does |
| --- | --- |
| Holds | What kind of stock it keeps: items, fluids, energy, or a stock you name (mana, gas, anything). Choose one of: Items, Fluids, Energy, A stock you name. |
| Stock name | The name of the stock it keeps, as the rules call it: mana, gas, souls. |
| Size | How much it holds of every kind together: items by count, fluids by the bucket's thousandths, energy and named stock by amount. From 1 to 1000000000. |
| Kinds | How many different kinds it holds at most. From 1 to 1000. |
| Only takes | The things it takes; anything else goes elsewhere. A fluid by its bucket. None: it takes anything of its kind. |

Every item also has the settings on the [Item](editor-item.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Storage disk.
