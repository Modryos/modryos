An item that takes a box of blocks round the block it is used on, chests with their items too, and places it back wherever it is used next, showing a ghost first.

## How to add it

- New thing > Blocks and items > Capsule


## What you can set

### Captures

| Setting | What it does |
| --- | --- |
| Takes | Blocks (with their contents), or a creature with all it is. Choose one of: Blocks, A creature. |
| When taken | Move lifts the blocks out and places them back once; Copy leaves them and builds a copy from the player's items. Choose one of: Move them, Copy them. |
| Which blocks | A box round the block used on, or between two corners (sneak and use on the first). Choose one of: A box round the block, Between two corners. |
| Width | How many blocks across, centred on the block used on. From 1 to 31 blocks. |
| Height | How many blocks high, from the block used on up. From 1 to 31 blocks. |
| Most blocks | It refuses a box with more blocks than this. From 1 to 32768. |
| Contents go too | A chest keeps its items and a machine its data. Off, they come back empty. |
| Mobs go too | Mobs inside the box are taken with the blocks. |
| Places | Only where all of it fits, where there is room, or over what stands there. Choose one of: Only if all fits, Where there is room, Over what stands. |
| Takes unbreakable | Takes blocks that cannot be broken, like bedrock. |
| Never takes | Blocks and groups it leaves where they are; at first, the blocks no mod may move. |
| Which creatures | Mobs and groups of mobs it may catch, such as cats; empty catches any but bosses. |
| Only your own | Catches only pets the player has tamed. |
| Turns with you | What it places is turned as far as you turned since it took it. |
| Shows a ghost | While held, a see-through ghost shows where it will place; red where there is no room. |
| Builds a second | How many blocks a copy builds each second. From 1 to 400. |
| Each use takes | An item taken from the player each use, such as an ender pearl; empty is free. |
| Cooldown | Seconds before it can be used again. From 0 to 600 seconds. |

Every item also has the settings on the [Item](editor-item.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Captures.
