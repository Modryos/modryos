An item the player uses on a block to remember a place, then on an aiming block to give it that place as its [target](glossary.md#target).

## How to add it

- New thing > Blocks and items > Designator


## What you can set

### Sets a block's target

| Setting | What it does |
| --- | --- |
| Marks the space above | On: the place it remembers is the space above the block it is used on (where a missile should land). Off: the block itself. |
| Also keeps it by name | A name: the remembered place is also kept by the world under it, so blocks that aim at that named place follow. Leave empty to only remember it. |
| Says what it did | Over the hotbar: the place it remembered, and the block it aimed. |

Every item also has the settings on the [Item](editor-item.md) page.

## What it becomes in the game

It is added to the game, so a player needs your mod to see it.

It comes with these abilities already on: Sets a block's target.
