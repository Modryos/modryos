A machine with a recipe that uses energy and time.

## How to add it

- New thing > Machines and networks > Powered machine

This makes several things at once: [Machine](thing-machine.md), [Machine recipe](thing-machineRecipe.md).

## What you can set

You set each part in its own editor, linked above.

## What it becomes in the game

Each part becomes what its own page says.

## What it works with

It does not point at other things.
