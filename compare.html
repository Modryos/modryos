Modryos and MCreator, compared.

Checked 22 October 2026. MCreator's facts come from its release notes and its source repository on that day.

MCreator is the best-known way to make Minecraft mods without code: free, open source, and used by a large community and in schools. Modryos is a newer desktop studio for the same job, and it is not released yet. This page sets out what each does today, including where MCreator is the better choice.

When MCreator is the better choice

  • You want to start today. MCreator is released and free; Modryos is not out yet.
  • You make Bedrock add-ons. Modryos makes Java Edition mods only.
  • You are on macOS or Linux.
  • You want a large body of tutorials, forum answers and plugins, or a tool already used in your school.

Where Modryos is different

  • One project makes the mod for NeoForge and Fabric, on five Minecraft versions from 1.21.1 to 26.3.
  • Models, textures and animations are made in the same studio as the rest of the mod.
  • Machines, energy, cables, fluid pipes and item ducts are built from parts, without code.
  • Quests, guide books and skill trees are part of the studio, laid out in the same screen builder as machine screens.
  • Rules read as sentences, and each one is Java underneath, so moving from sentences to code is one click.

Other tools people use to make Minecraft mods

Each of these is the best at something. Several work well beside Modryos or MCreator rather than instead of them.

Blockbench

A free, open-source editor for low-poly models, textures and animations, on Windows, macOS, Linux and the web, with plugins. It makes the models a mod uses; it does not make the mod itself.

KubeJS

A mod that lets modpack makers change recipes and add content with JavaScript. The strongest choice for reshaping a modpack's recipes, and it needs scripting.

Misode's generators

Web forms for data pack files: world generation, loot tables, recipes and more. They make the files of a data pack, not a mod.

FTB Quests

A mod with an in-game quest editor, used by many modpacks. Players need the mod installed to see the quests.

Patchouli

A mod for in-game guide books, written as data files. Players need the mod installed to read the books.
