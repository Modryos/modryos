Modryos / FAQ

Questions and answers.

Last updated 22 October 2026

Can you make a Minecraft mod without coding?

Yes. In Modryos you choose what to make, fill in its settings, create its model and texture, and build its rules from ready-made sentences. Modryos writes the Java code for you, and you can test the mod in the game from the app.

Do I need to know Java?

No. Rules are built from ready-made sentences, such as "when the sword hits something, set it on fire". Each rule is Java code underneath, and you can open the code at any time. You can also add your own Java classes and mixins.

What is Modryos?

A desktop app for making Minecraft Java Edition mods: models, textures, animations, creatures, items, recipes, machines, screens, quests and rules, in one project. You can test the mod in the game from the app.

Which Minecraft versions does Modryos support?

Minecraft Java Edition 1.21.1, 1.21.11, 26.1.2, 26.2 and 26.3.

NeoForge or Fabric?

Both. One project builds the mod for NeoForge and Fabric on all of these versions. Modryos creates a jar file for each version and loader you choose.

Does Modryos make Bedrock add-ons?

No. Modryos makes Java Edition mods, data packs and resource packs. Bedrock Edition uses add-ons instead of mods.

What can I make with it?

Blocks, items, tools, weapons, armour and food; creatures with behaviours that can be tamed and ridden; crafting and other recipes; machines with energy, cables, fluid pipes and item ducts; machine screens, HUD bars, books, bestiaries and skill trees; quests on a map; and data packs and resource packs. The features page shows each one in the game.

How do I test my mod?

Click Play. Modryos starts Minecraft with your mod on the version and loader you choose, with one or two players on the same PC. Recipes and other data update with a reload, and many code changes apply while the game is running, so most changes do not need a restart.

Can I put my mod on CurseForge or Modrinth?

Yes. Modryos builds the mod's jar files, one for each version and loader, and you upload them yourself. Goat Apples, the first mod made with Modryos, is on CurseForge.

Do the recipes show in JEI?

Yes. The recipes appear in JEI and other recipe viewers.

Which computers does Modryos run on?

Modryos is a desktop app for Windows.

Is Modryos made by Mojang?

No. Modryos is not an official Minecraft product, and it is not approved by or associated with Mojang or Microsoft.
