Modryos / FAQ

Questions and answers.

Last updated 22 October 2026

Can you make a Minecraft mod without coding?

Yes. A mod maker lets you build the mod's parts through forms, editors and visual rules, and writes the Java for you. In Modryos you pick what to make, fill in its settings, shape and paint its model, write its rules as sentences, and press Play to open it in the game.

Do I need to know Java?

No. Rules are sentences you pick from, such as "when the sword hits something, set it on fire". Each sentence is Java underneath and the code view is one click away, so you can read the Java when you want to. When you want code of your own, your own Java classes and mixins sit beside the rules in the same project.

What is Modryos?

A desktop studio for making Minecraft Java Edition mods: models, textures, animations, creatures, items, recipes, machines, screens, quests and the rules that tie them together, in one project. Press Play and the mod opens in the game.

Which Minecraft versions does Modryos support?

Minecraft Java Edition 1.21.1, 1.21.11, 26.1.2, 26.2 and 26.3.

NeoForge or Fabric?

Both. The same project makes the mod for NeoForge and for Fabric, on each of those versions. You choose which one to Play, and Modryos builds the jar files for the versions and loaders you choose.

Does Modryos make Bedrock add-ons?

No. Modryos makes Java Edition mods, data packs and resource packs. Bedrock Edition uses add-ons instead of mods; MCreator is one tool that makes them.

What can I make with it?

Blocks, items, tools, weapons, armour and food; creatures with behaviours that can be tamed and ridden; crafting and other recipes; machines with energy, cables, fluid pipes and item ducts; machine screens, HUD bars, books, bestiaries and skill trees; quests on a map; and data packs and resource packs. The features page shows each one in the game.

How do I test my mod?

Press Play. Modryos starts Minecraft with your mod on the loader and version you pick, with one player or two on the same PC. Data such as recipes reaches a running game with a reload, and many code changes are swapped in while it runs, so most changes do not need a restart.

Can I put my mod on CurseForge or Modrinth?

Yes. Modryos builds the mod's jar files, one for each version and loader, and you upload them yourself. Goat Apples, the first mod made with Modryos, is on CurseForge.

Do the recipes show in JEI?

Yes. The recipes a mod adds show in JEI and the other recipe viewers.

How is Modryos different from MCreator?

MCreator is released, free and open source, makes Bedrock add-ons as well as Java mods, runs on Windows, macOS and Linux, and has a large community. Modryos is not released yet. It makes one project for both NeoForge and Fabric on five versions, and has a model editor, machines with pipes and cables, and quests in the same studio. The comparison sets out both, side by side.

Which computers does Modryos run on?

Modryos is a desktop app for Windows.

Is Modryos made by Mojang?

No. Modryos is not an official Minecraft product, and it is not approved by or associated with Mojang or Microsoft.
